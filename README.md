# PulsePoint — Student Feedback Web Application

A simple, aesthetic student feedback application built with HTML, CSS and JavaScript, with a GitHub Actions CI/CD workflow.

## Features
- Student name, course and feedback form
- Interactive feedback cards
- LocalStorage persistence
- Responsive design
- Solid blue/cyan visual theme
- GitHub Actions CI/CD workflow
- GitHub Pages deployment

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages deployment
1. Push this project to a GitHub repository.
2. Open **Settings → Pages**.
3. Set **Source** to **GitHub Actions**.
4. Push to `main`.
5. The workflow in `.github/workflows/deploy.yml` deploys the site.

## DevOps flow
Developer → GitHub → GitHub Actions → Build/Validation → GitHub Pages → Live Website
